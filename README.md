# Interactive Sales Analytics Dashboard

## Overview
This project presents an interactive Sales Analytics Dashboard built in Microsoft Excel using Pivot Tables, Pivot Charts, Slicers, and VBA Macros. The dashboard transforms raw sales data into actionable business insights, enabling users to analyze sales performance across different regions through dynamic filtering and automated controls.

## Key Features

### 1. Top 5 Sales Executives Analysis
- Displays the top 5 performing sales executives based on total sales.
- Includes an interactive Pivot Chart for visual comparison of top performers.

### 2. Bottom 5 Sales Executives Analysis
- Displays the bottom 5 sales executives based on total sales.
- Uses a Pivot Table for performance evaluation.
- No Pivot Chart is included for this section.

### 3. Target Achievement Analysis
- Shows the top performers ranked by Target Hit Percentage.
- Includes an interactive Pivot Chart for performance visualization.

### 4. Away From Target Analysis
- Displays sales executives ranked by Away From Target Percentage.
- Includes a Pivot Chart to identify performance gaps.

### Region-wise Filtering
- Implemented Excel Slicers for dynamic region-based analysis.
- Users can instantly switch between regions and view updated results across all dashboard components.

### VBA Automation
- Developed VBA-powered checkbox controls to dynamically show or hide dashboard sections.
- Users can customize the dashboard view by selecting only the reports they want to analyze.
